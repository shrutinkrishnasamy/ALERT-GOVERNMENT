# 🚨 ALERT-GOVERNMENT

An AI-powered Government Emergency Alert Management System designed to help government authorities send **location-based emergency alerts** quickly and efficiently through mobile networks.

The system enables officials at different administrative levels (VAO, Taluk, District, Collectorate) to create, review, approve, and broadcast multilingual emergency alerts to citizens in affected areas.

---

## 📌 Project Overview

ALERT-GOVERNMENT is a web-based platform that streamlines emergency communication between government authorities and the public.

The system allows administrators to:

- Create emergency alerts
- Select affected locations on a map
- Identify nearby mobile towers
- Generate multilingual alert messages using AI
- Approve alerts through the government hierarchy
- Send alerts to citizens through Cell Broadcast technology

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shrutinkrishnasamy/ALERT-GOVERNMENT.git
```

Move into the project directory

```bash
cd ALERT-GOVERNMENT
```

Run the application

```bash
mvn spring-boot:run
```

Application runs on

```
http://localhost:8080
```
